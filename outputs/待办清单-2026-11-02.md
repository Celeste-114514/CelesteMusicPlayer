## 11-05 Native DSD 交付（代码已完成，待你实机验收）

**做了什么**：设置里「DSD 输出方式」多了一档 **「原生 DSD（ASIO）」**。选中后，DSF 的 1-bit 码流不再装箱成 DoP、也不转 PCM，直接经 ASIO 驱动送进 DAC。软件音量 / EQ / 重采样在这条路上强制旁路（DSD 不能线性缩放，否则满耳噪声）。驱动不支持或守卫不满足会自动回退 DoP / PCM，并在日志写明原因。

**实机探测结论**（工具 `tools/DsdAsioProbe/`）：
- 驱动 FiiO ASIO Driver，原生 DSD 格式切换成功；**DSD64 / 128 / 256 全支持，DSD512 不支持**（正好是 KA13 上限）。
- 驱动要求 MSB-first（采样类型 33），主流 DSF 是 LSB-first，代码逐字节做了反转。
- 3 秒静音码流实播：无崩溃、欠载 0 次、驱动完整还原成 PCM / 48000。

**怎么验**（四步，都在播放器里点）：
1. 关掉播放器再打开（新 DLL 已同步进 `dist/bugfix-20261104-borderless/`，快捷方式不用改）。
2. 底栏「音频设置」把输出模式切到 **ASIO**，设备选 **FiiO ASIO Driver**。
3. 设置 → 播放与音频 →「DSD 输出方式」选 **原生 DSD（ASIO）**。
4. 播一首 **DSF**（DSD64/128/256、1–2 声道）。看 KA13 机身窗口的灯：**绿色 = 收到 DSD**；链路面板应显示 `Native DSD …Hz / 1-bit`。

**没做的 / 限制**：只支持 DSF（DFF 仍走 DoP/PCM）；暂不支持拖动进度与分轨（会自动回退）；没有无缝切歌；**真 DSF 文件还没实机播过**，上面 3 秒自测用的是合成静音码流。这几条等你试完再定要不要补。

**回退**：旧 DLL+PDB 在 `dist/_native_dsd_rollback_20261105/`；整份旧版本仍在 `dist/bugfix-20261104-opaque-snap/` 等目录。把设置里的 DSD 输出方式改回「DoP 直出」或「转成 PCM」即可立刻恢复原行为，不用换程序。
