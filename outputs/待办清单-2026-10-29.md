## 3. 新增主线：完整网页样式包（P0–P4）

> 方案原文：`collab/PLAN-2026-10-29-player-page-pack.md`（本节是它的待办化摘要，冲突时以原文为准）。
> 排期：按你的决定，**排在零散播放器重构之后**。P1–P3 完成前，**不得把现在的 JSON 改色包说成「完整页面包」**。

### 3.1 和现在这套的区别（一句话）

现在能改的是「颜色、字号、封面位置」这类**参数**；新方案要的是作者用 **HTML/CSS/JS 自己画整个页面**，程序只提供数据（歌曲、进度、歌词、外观、频谱）和动作（播放、seek、音量…），**不另起音频引擎**。

### 3.2 包长什么样

- 扩展名 `.celeste-player`，内容就是 ZIP：`manifest.json` + `views/detail|mini|quick/index.html` + `assets/` + `preview.webp` + 可选 `options.schema.json`。
- manifest 声明：格式标识、schema/api 版本、作者与许可、每个 view 的入口与**最小/推荐尺寸**、呈现模式（整页 or 只做背景）、能力清单。
- 适用范围：**detail**（主播放详情页）、**mini**（主会话小窗）、**quick**（零散独立会话）。一包可含多个 view，但必须分别声明入口和适配尺寸，不许把一份大页面硬缩。

### 3.3 分阶段待办

| 阶段 | 要做的事 | 交付/验收 |
|---|---|---|
| **P0 契约与模板** | 冻结 manifest 和数据结构版本；写自带模板、字段说明、模拟数据预览器、打包检查工具 | 三个默认界面能用同一套数据适配概念；**现有 JSON 预设继续可用** |
| **P1 运行时** | 隔离方案先做 PoC（WebView2 frame 桥接 / CSP / MessageChannel），验明后再固化；主题资源服务；握手 / 卸载 / 回退 | 两个风格完全不同、你自己做的 detail 示例；**切主题不断播** |
| **P2 本地库** | 安装 / 预览 / 应用 / 更新 / 导入导出；作者选项；每包私有存储；原子安装、只读资源、版本并存可回退 | 干净配置导入后能复现；导出不含曲库/凭据/本机路径 |
| **P3 mini 与 quick** | 分别绑主会话 / 零散会话；控制归属（controls=host 或 page，只能有一套） | 布局明显不同的小窗实例；窗口尺寸 / DPI / 拖动 / 关闭 / 控制归属全验 |
| **P4 可视化与作者工具** | 频谱/能量按需订阅（降采样、不传原始 PCM、隐藏即取消）；模拟状态与歌词；兼容检查与教程 | 性能预算达标；可视化**拖拽编辑器明确不在首期** |

### 3.4 硬边界（写进待办，别到实现时忘）

- 作者页面放**独立受限上下文**：宿主只转发「当前实例 / 当前会话 / 当前 generation」的白名单消息；页面拿不到 `chrome.webview` 通用访问、文件、输出引擎、DSP、账户对象。
- 生命周期 `load→ready→activate→update→deactivate→dispose`；握手超时 / 脚本异常 / 版本不兼容 → **保留默认界面**，用户随时可从外层恢复。
- 图片/视频/字体必须是包内资源，**默认禁止外网脚本**；入库前检查路径越界、符号链接、重复路径、解压体积、文件数。
- 主题界面怎么崩，**都不能影响音频播放状态**。
- 参考素材的许可：ECHO 工坊包可借鉴协议设计但**不承诺直接加载**；Apple Music 包是 All-Rights-Reserved，官方示例要自行创作；用物语（MIT）素材须保留署名与许可。
