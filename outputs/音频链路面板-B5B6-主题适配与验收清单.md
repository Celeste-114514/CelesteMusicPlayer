> 面板已按 Echo「信号路径」风格做完（B1~B4），入口 = **标题栏右上角**那个按钮（原「音频设置」）。

## 一、B5 主题适配（代码侧已做 / 待你实机核对）

| 项 | 处理 | 你要看的 |
|---|---|---|
| 浅色主题 | 面板底 `#FBFBFD`，文字用主题前景色，强调色蓝紫 `#6C5CE7` | 白底上文字是否清楚、灰字是否太淡 |
| 深色主题 | 面板底 `#202024`，强调色提亮为 `#A99BFF`，标签/胶囊各有深色档 | 深色下标签胶囊的底色是否脏、橙字（诊断标题）是否刺眼 |
| 窄窗口 | 面板宽度 = min(420, 窗口宽 − 40)，两侧至少留 40px | 把窗口拖窄看看面板有没有贴满整屏、有没有内容被挤到变形 |
| 长文本 | 双列网格里"长值 / 长说明"自动判成整行跨两列（值 > 22 字或说明 > 26 字） | 「限制说明」「设备未声明采样率…」这类长句是否完整换行、有没有把另一列挤扁 |
| 超长曲名 | 节点标题、时间线变化行单行截断（省略号） | 长歌名会不会把面板撑宽 |
| 图标 | 全部用 Segoe 字体图标（与标题栏/左栏同一套） | 有没有出现方框（= 字体缺字形，有的话告诉我哪个节点） |

## 二、B6 验收清单（照着点，逐条打勾）

### A. 打开与关闭

- [ ] 点标题栏右上角按钮 → 面板从右缘滑出（不是从中间弹出、不是盖住整个窗口）
- [ ] 再点一次同一个按钮 → **不会消失**（已打开时再点只忽略）
- [ ] 点右上角 × → 收起
- [ ] 点面板外的暗色区域 → 收起
- [ ] **开 → 关 → 再开**，来回三次都能正常出来（这是之前修的那个坑）
- [ ] 面板上下留白 ≈ 100px，不贴窗口顶/底

### B. 顶部区

- [ ] 标题是「信号路径」，右上角是小叉（不是大圆钮）
- [ ] 摘要行左边是音源摘要，右边是「N 层链路」灰色胶囊
- [ ] 未播放时：摘要不显示音源、层链路胶囊按实际层数显示

### C. 处理阶段 + 电平

- [ ] 阶段大标题（20px 粗体）：未播 =「待命」，播了且没 DSP =「原生播放」，有 DSP =「DSP 处理中」
- [ ] 阶段下一行小字跟着变（"未启用 DSP" / "N 个模块在链上"）
- [ ] 没播时电平数值是双短横线，24 段全灰
- [ ] 播放中电平条会亮、数值跟着跳（post-DSP 峰值）
- [ ] 刻度行显示 -60 / -24 / -12 / -6 / 0 dBFS

### D. 双列参数

- [ ] 「来源」「处理」两列宽度均衡，标签小灰、值深色加粗
- [ ] 输出设备 / 输出模式 / 内部处理格式 / 实际输出 / 输出缓冲 都如实显示
- [ ] 开了卷积才出现「卷积延迟」，倍率≠1 才出现「变速」（没开就不出现，不是显示"未启用"）
- [ ] 「DSP 实时余量」：没播 = 等待信号 + "未在实时播放"；不出现假的 CPU/处理速度

### E. 技术档案胶囊

- [ ] 一行排不下会自动换行（不是挤成一条）
- [ ] 音量、回放增益、均衡器、房间校正、压缩器、重采样 各一枚，开关状态跟着变
- [ ] 软件音量生效时那枚是橙色（警告色）

### F. 音频链路节点

- [ ] 顺序：解码 → PCM 缓存 → 无缝接力 → 降混 → 变速 → DSP → 输出安全 → 输出
- [ ] **只显示已开启的 DSP 模块**；一个都没开就只有一枚「DSP · 未启用」
- [ ] 每个节点左侧有图标 + 竖线串起来（最后一个节点没有拖尾竖线）
- [ ] 图标跟标题栏/左栏是同一套风格，没有方框

### G. 链路诊断（默认展开）

- [ ] 标题右边显示「N 条提示」（蓝紫色）
- [ ] 每条：左边截断的类别（如 BIT-PERFECT），右边橙标题 + 原因 + 建议
- [ ] 点标题能折叠/展开，折叠后真的变矮（不是留一片空白）
- [ ] bit-perfect 时整块不出现

### H. DAC 能力图谱（默认收起）

- [ ] 没播 / 拿不到设备名时整块不出现
- [ ] 展开后显示本次协商格式、设备路径判定

### I. 输出记录（默认收起）

- [ ] 标题右边显示「当前曲目 N 条 / 共 M 条」
- [ ] 展开后是时间线：左时间戳、中间轴线 + 圆点、右边三行（曲目 / 事件名 / 变化）
- [ ] 切歌 → 出现「曲目切换」；换设备 →「输出设备」；切模式 →「输出模式」；起播 →「格式协商」
- [ ] 拖 EQ 滑块不会刷出一整屏重复行（同值去重）

### J. 稳定性反馈

- [ ] 小标签「稳定性反馈」+ 深色总结标题 + 灰字说明
- [ ] 下面双列：请求模式 / 实际确认路径 / 是否回退 / DSP 状态（+ 限制说明，只有非 bit-perfect 才出现）
- [ ] 底部「打开音频设置」点了能打开设置面板（并自动收起链路面板）

### K. 实际场景走一遍

- [ ] 播一首 MP3（共享模式）→ 诊断应出现"不是 bit-perfect（共享输出）"
- [ ] 切到独占模式 → 诊断消失或变化，稳定性反馈跟着变
- [ ] 播一首 96k/24bit → 看「内部处理格式 / 实际输出」是否如实
- [ ] 开 EQ → 阶段变「DSP 处理中」，链路里多一枚 EQ 节点，技术档案"均衡器已启用"
- [ ] 倍率调到 1.25× → 多出「变速」字段，诊断出现"变速播放中"
- [ ] 播一首 DSD → 链路显示 DSD/DoP 直出相关文案（不崩、不显示假格式）
