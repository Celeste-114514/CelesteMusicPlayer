同一个空间，不弹新窗口

柜子 → 抽屉 → CD 机是镜头与物体的连续动作，三层共用一套材质和光照。抽屉外框退到后方作为「来源提示」，不遮住唱片。

封面只在第二层出现

第一层只看铭牌与侧脊；第二层非选中项侧转约 55–65° 露出部分封面，选中项前探转正露出完整封面与专辑名 / 年份 / 曲数。

选中与播放是两件事

浏览别的专辑时 CD 机仍放原来那张。要换歌必须按「放入 CD 机」，装载动画结束后才发一次播放命令。

第三层（未画屏）

镜头推近 CD 机：盒子停靠 → 盘片沿路径进入机芯 → 盖板闭合 → 盘片旋转、指示灯亮。场景内自带播放 / 暂停、上下曲、真实进度与音量，因为底部播放条会被覆盖。

想请你先拍板这四件事

  1. 整体气质：暖白金属 / 陶瓷柜体 + 磨砂玻璃抽屉 + 细窄琥珀指示光，放在深色空间里。要不要换成更冷、更暗的方向？
  2. 第一层不显示专辑封面、只看铭牌和侧脊——这是方案里的明确要求，确认保留吗？
  3. 第二层右侧 CD 机常驻可见（约 38% 宽度），第一层只低调停在背景。可以吗？
  4. 默认排序按发行年份升序，缺年份靠后；第二层可切换排序并带重排动画。有没有更习惯的默认（例如按专辑名）？
