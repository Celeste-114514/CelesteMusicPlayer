# 2026-10-11 皮肤系统批次 1：Windows 风（Fluent）平行主页 winmain.html

## 落地内容（提交 c411a34，已推送 4235569..c411a34）

- **winmain.html**（WebUI/，4994 行新文件）：main.html 的平行换肤页。Segoe UI Variable
  Text 字体栈、Segoe Fluent Icons 字形（.gi 45 处）、五处 backdrop-filter 毛玻璃 +
  Mica radial-gradient、控件圆角全 4px、开关 10px、滑轨 4px/钮 20px、过渡 100ms。
  **DOM 结构与消息协议零改动**（songact 5=5、albumact 4=4 等钩子逐一比对），C# 侧
  不复制 3400 行推送逻辑，直接复用 WebMain 那套。
- **C# 共享开关设计**（MainWindow.WebWin.cs 新建 89 行）：`_webMainOpen` 共用主开关
  （推送/每秒定时器/消息分发全看它）；`_webWinOpen` 只记「当前加载哪张页」；两入口
  互斥（开 winmain 先 CloseWebMain，反之亦然）；`CloseWebMain()` 统一出口一并复位
  `_webWinOpen`——漏了这行的症状是「关掉后再点新版界面按钮失灵」（被"已经是
  Windows 风页"守卫挡掉）。`_webMainOpening` 作唯一打开中闸门防连点双导航。
- **XAML**：歌曲库工具栏「Apple 风格界面」pill 旁新增「新版界面」pill（E8A9 字形，
  ToolTip 说明 Fluent），同在 SongSortPanel（仅歌曲/用户播放列表分类可见）。
- **csproj**：winmain.html Content 随包。

## _webcheck harness 页面维度参数化（WB_PAGE）

- `build_harness.py`：产物名 `out_<场景>[_<页>].html`；**main/dsp 不加后缀**（保住既有
  文件名与老断言零改动），平行页（winmain）加 `_winmain` 后缀，两套产物共存。
  默认清单加 np、skin 两场景。
- `run_all.sh`：`PAGE="${WB_PAGE:-main}"` → SFX；dsp 场景单独强制 `sfx=""` 且只在
  main 套跑（dsp 场景跑的是 dsp.html）。
- `scen_skin.js`（新）：getComputedStyle 实采换肤事实（字体栈首位、.gi 字体/非斜体、
  圆角、过渡时长、轨/钮尺寸、backdrop-filter、Mica）+ 样式表 cssText 文本级扫描
  （outline:0 残留、字面怪圆角 5/7/9/11/13px、字面过渡 >300ms；16px pill 与 10px
  开关胶囊是 Fluent 标准件放行）。**注意 `document.fonts.check` 才是规范挂点**
  （`window.fonts` 在本页面取到 undefined）。
- `scen_np.js`：svgIn 重构为 IIFE 平铺 map，新增 giIn 同款，供按页面分流断言
  （winmain 期望全 gi 无 svg，main 期望全 svg 无 gi）。
- `assert_state.py`：np 块（lyrCurIdx=='10'=第 6 句，场景 t=i*12、pos=65，**不是 12，
  最后一句 t<=65 的原文行是第 6 句 t=60**）+ skin 块（共享区=两页共同：无 errors、
  行高 62px、顶栏/页头/播放条 44/98/90、过渡 <=300ms；winmain 分支=无 outline:0、
  无怪圆角、Segoe UI Variable Text、gi>=20、毛玻璃五处、控件圆角 <=8；main 分支=
  giCount==0、-apple-system、无 backdrop 对照基线）。
- **结果：winmain 25 场景 + main 26 场景双套全绿，P1~P8 一条不删。**
