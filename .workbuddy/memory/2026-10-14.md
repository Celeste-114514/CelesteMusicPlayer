# 2026-10-14 标签板块

## 修「读不出文件夹」（真根因，非表格问题）
- 现象：点「添加文件夹…」选完文件夹后什么都加不进来，随后连「添加文件…」也坏。
- 日志实据：`logs/lib/2026-10-14.log` 连着 6 条
  `TypeInitializationException: The type initializer for 'CelesteMusicPlayer.TagPanelControl' threw an exception`。
- 根因：`TagPanelControl` 有静态字段 `static readonly Brush TagFallbackAccentBrush = new SolidColorBrush(...)`。
  首次触碰该类型发生在**后台线程**（AddFolderButton_Click → Task.Run → EnumerateAudioFiles 读
  TagAudioExtensions），在非 UI 线程创建 DependencyObject 抛异常 → CLR 把整个类型永久标记为
  不可用 → 之后 UI 线程上任何访问（添加文件/文件夹）都炸。
- 修法：静态成员只留纯值 `static readonly Windows.UI.Color TagFallbackAccentColor`，
  画刷在调用点 new（调用点全在 UI 线程）。
- **铁律**：本文件（以及任何会在 Task.Run 里被首次触碰的类）禁止在静态初始化器里 new 任何
  DependencyObject（Brush / SolidColorBrush / TextBlock …）。
