# 2026-10-15 工作日志

## DSP 声道矩阵 L/R 字母居中 + 本机抽风导致的一连串发布坑
- 用户报「DSP 面板声道矩阵可视化坏了，应该是个圆」→ 自纠「没坏，只是 L/R 字母不在正中心」。
- 根因：`MainWindow.DspMatrix.cs` 的 `MakeMatrixNode` 用 **Canvas** 作节点容器，**Canvas 不认 Horizontal/VerticalAlignment**，里面 TextBlock 默认塌到左上角 → L/R 偏在圆点左上。修法=Canvas 改 **Grid**（对齐才生效），椭圆显式 Center。已编译+冒烟通过。
- 交付 run-latest 时撞上本机 CPU 故障大抽风，连踩四坑（详见 MEMORY.md「构建与发布」新增三条）：
  1. 上一轮增量发布把 run-latest 里某个原生 DLL 拷坏 → 启动前无日志的 0xC0000005 静默退（**不是源码问题**：撤掉我的改动重发照样崩，而旧好备份能启动，坐定是坏文件）。
  2. 只清 obj/x64 不清 bin/x64 → 0 字节 .g.cs 反馈环，XamlCompiler 连崩；**两个一起清**才过。
  3. 漏 `-p:CelesteSelfContainedDistribute=true` → 出 177KB 依赖运行时版 exe，混搭在 Main begin 后以 3221227010 退；自包含 exe 应≈303KB。
  4. 全量自包含发布的**原生 DLL 被拷坏** → CLR `0x80131506`。
- 最终稳解：**好备份整体回填 run-latest（原生 DLL+自包含 exe 完好）+ 覆盖带自包含开关编出的正确 dll（2,729,984B）**，冒烟 `SUSPECT_LINES=0`、完整启动（媒体库 4031 首）。
- ⚠ 冒烟中途出现 `relay command: ACTIVATE:`+`returncode=0`：是**单实例**机制，有残留进程占锁（PowerShell Stop-Process 清掉再冒烟）。
- ⚠ 未做视觉确认（禁 UIA 点击铁律），L/R 居中由用户实机核对。
