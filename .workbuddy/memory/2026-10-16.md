### 四个 UI 问题与根因（重要，别再踩）

1. **左栏收起/展开图标位置不一致 + 收起后点另一个分类整列左偏 —— 是同一个 bug**
   - 根因：两处代码各写各的对齐。`SetLeftNavIconMode`（MainWindow.Misc.cs）收起时设
     `HorizontalContentAlignment=Center`；而切换分类走到的 `UpdateLibraryNavHighlight`
     （MainWindow.Library2.cs，两处分支）里写死 `HorizontalAlignment.Left`，点一次就把
     Center 覆盖掉 → 视觉上"整列图标往左偏"。
   - 修法：新增 `private static HorizontalAlignment NavContentAlignment => Left;` 作单一真相源，
     三处调用点全部改用它。收起态也不再切 Center，与展开态严格同位置。
   - **教训：以后任何"同一属性在多处赋值"的 UI 状态，必须抽单一真相源，否则切换路径一覆盖就复发。**

2. **波形进度条下方按钮组太靠右**：`UpdateTransportProgressCentering` 里按钮组和进度条
   共用 `TransportProgressShiftX = 96`。拆出 `TransportButtonsShiftX = 0`，按钮组回落到
   播放栏正中（相对原来左移 96px）。

3. **波形每根竖线太细**：桶数 180 摊在 660px 上，每根净宽只有约 2.6px。
   桶数 180→120、柱间缝 1.5→1.2、柱宽下限 1→1.5、进度条固定宽 660→720 → 每根约 4.8px。
   ⚠ 改桶数会让已缓存波形全部重算一次（缓存按桶数校验），属预期。

4. **播放状态栏偏窄 + 上方贴顶线**：`MinHeight` 70→82、`Border.Margin` 上 1→10、
   `Padding` 16,6,16,10→16,12,16,12（整栏 86→106）。

5. 默认窗口 `ResizeWindowToDips(1400, 800)` → `(1480, 860)`；
   最小尺寸 `MinWindowWidthDip/HeightDip` 仍锁 1400×800 没动（保证还能拖小）。
