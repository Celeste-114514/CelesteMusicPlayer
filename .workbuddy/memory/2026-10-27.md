### 这一轮踩到 / 定下的东西（后续别再摸错）
- **字体族名必须加引号**：`font-family: Microsoft YaHei UI` 不加引号整条会失效；宿主统一 `QuoteFamily`。
- **注册表枚举字体**：`HKLM\...\CurrentVersion\Fonts` 的值名 = 族名（TTC 用 ` & ` 连多个族，`@` 开头是竖排变体要丢）。
  不要列 .ttf 文件名，文件名≠族名，给错名字 CSS 静默回退。
- **字号变量化**：`calc(Npx * var(--text-scale))`，clamp 要上下限各自缩放。抽了脚本 `_scale_fonts.py`。
- **取色器不吃 8 位颜色**：`#RRGGBBAA` 塞给 `input[type=color]` 会变黑，透明度丢失。
  colorRow 现在只取 RGB、写回时把 alpha 接回去（遮罩/投影靠这个）。
- **背景层三个坑**：
  ① `.shell` 原本满铺实心底色，图根本露不出来 → 非纯色模式给 `<html data-bg>` 让 `.shell` 变透明；
  ② `.shell` 的直接子元素必须 `z-index:1`，否则标题栏被图盖住；
  ③ `bg-image` 为空要**显式写 none** —— applyCss 只覆盖不清理，省略会让上一张图一直挂着。
- **图片通道**：CSP 不许 file://，必须拷进 `%LOCALAPPDATA%\CelesteMusicPlayer\webbg`
  再 `SetVirtualHostNameToFolderMapping("celeste-asset.internal", …)`；CSP 的 img-src 要放行这个 host。
- **SVG 几何联动**：轮盘半径改了必须同时重写四条引导弧的 `path d`（core=r1-45、inner=r1+45、edge=max(inner+20,r2+42)），
  只改 CSS 不动 d 就会图标跑出轨道。
- **导航每圈至少留一个可见项**：整圈收起来时 JS 要除以 (n-1) → NaN → 项目全叠左上角。宿主 Normalize 里顶回来。
- `WebAppearanceAsync` 改成 `async Task<object>`（要等文件选择框），`WebShellWindow` 里补了 await。

### 这轮的判断
- **DSP 导航指示条**：一根绝对定位的条，跟着 `[aria-current=true]` 项走。
  位置用 `offsetLeft/offsetTop`（相对 nav 的 padding box），不要用 `getBoundingClientRect`
  混算 —— nav 有 1px 边框，两套坐标系差 1px，看起来就是"没贴边"。
- **`z-index:1` 是必须的**：导航项自己 `position:relative` 且排在指示条之后，
  不加这层会被当前项的渐变背景盖住 → 看到一条洗淡的粉边。第一次截图就抓到了。
- **重绘分两种**：`renderModule()` = 换模块（放入场）；`renderModule(false)` = 参数回读刷新（不放）。
  开关写回成功会重绘一次，照放动画就是每拨一下整块内容在晃。
- **机架重排不能用通用 FLIP**：`motion.flip(elements, mutate)` 要求前后同一批节点，
  重排会重建 `<li>`。改成按模块名记旧位置、重排后逐行算位移。
- **失败要给重试入口**，不能停在一句错误上（模块/方案/机架/网络目录四处都按这个改了）。
- **逐文件失败就地列出**，不要只 throw 第一个 —— 用户会以为只错了一首。

- 该类崩溃是**随机**的（skill 写死 ~50% 失败率），**没有神奇开关**：

## 第三批续：列表重排 + 设置指示条（13:4x）

- **列表 FLIP 不能用现成的 `motion.flip()`**：它要求前后是同一批节点，而歌曲/专辑/艺术家
  都是 `replaceChildren` 整体重建。新增 `motion.captureRows/replayRows` 按行自己的
  `data-flipkey` 对齐，换节点也能算出位移。
- **网格必须算横向位移**：一排卡片换序只有 dx，没有 dy。第一版只算纵向 →
  "顺序变了但完全没动"，被新冒烟当场抓到。
- **设置页点分类不能重建导航栏**：原来每次点击 `renderNav()`，共享指示条跟着被重建，
  "滑过去"永远做不到。改成就地切 class + 摆指示条。
- 顺手修 `WebShellStateSmoke` 的假阴性：过渡中 Chromium 把不透明色序列化成
  `rgba(r,g,b,1)`，字符串相等会偶发失败 → 按通道比较（±1）。**22 个网页冒烟全过。**
