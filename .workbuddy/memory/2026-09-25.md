## 两个 UI/曲库 bug 修复（00:40~00:50，提交 c0da19e）
1. **媒体库右键「从媒体库中删除」文件夹后，该文件夹的歌仍留在「我的音乐库」**
   - 根因（MainWindow.Library.cs 原删除分支）：只做 `settings.LibraryWatchFolders.RemoveAll` + `Save` + `RefreshFolderBrowserRoots()`，**没动已收录的 `_playlist`**。
   - 修法：新增 `RemoveFolderTracksFromLibraryAsync(folderPath)` —— 按 `Path.GetFullPath` 前缀（含子目录）收集该文件夹下曲目 → `RemoveFilesFromCurrentPlaylist(deadPaths)`（内部会清 `ManualLibraryFiles` 记录，**否则重启后被 AppendManualLibraryFilesAsync 补回来**）→ `RemoveSongsFromUserPlaylist` 清播放队列 → `RenumberCollection` ×2 → `NotifyCurrentPlaylistWindow` → 重建专辑/艺术家视图（`RefreshAlbumViewAsync`/`RefreshArtistViewAsync`）。
   - 复用点备忘：批量移除有现成 `RemoveFilesFromCurrentPlaylist(IEnumerable<string>)`（Playback2.cs:1336）；单曲版 `RemoveSongFromAllCollections`（Playback2.cs:2092，末尾就是 Renumber+刷专辑/艺术家的标准收尾）。
2. **专辑分类右上角只剩升序/降序，排序字段下拉不见了**
   - 根因：切到歌曲库/播放列表时 `AlbumSortButton.Visibility = Collapsed`（MainWindow.Features.cs 两处），**切回专辑分类时无人把它设回 Visible**（面板 AlbumSortPanel 可见了，按钮自身仍隐藏）。
   - 修法：那两处改为折叠整个 `AlbumSortPanel`（语义正确），并在 `UpdateAlbumSortButtonsUi()` 里复位 `AlbumSortButton.Visibility = Visible` 双保险。
