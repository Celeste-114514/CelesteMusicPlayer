## 第三轮：弹窗定位改正（用户明确要的行为）

**用户需求原话**：「除了在右侧的那个音频设置按钮没办法以外，这两个窗口都应该
以按钮的水平位置为中轴位置上左右对称」。

我上一轮把 `#transport-dialog` 用 CSS `left:50%;top:50%;translate:-50% -50%` 强行居中是**错的**，
因为 `transport-panels.js` 的 `placePanel()` 本来就在按触发按钮定位，写的是 **inline left/top**。
inline 会盖掉 CSS 的 left/top，**但盖不掉 CSS 的 translate** → 面板在被算好的位置上又偏半个身位。

正确做法：
- `placePanel()` 的 left 算法改成**按钮水平中心对齐**：`anchor.left + anchor.width/2 - width/2`
  （原来是 `anchor.right - width`，纯右对齐），再 clamp 到 `[16, innerWidth-width-16]`。
  音频设置按钮太靠右 → clamp 后贴边，无法对称，这正是用户说的"没办法"，属预期。
- CSS 只留无锚点兜底：`right:24px;bottom:134px`（播放栏 108px + body padding 14px + 12px 间隙），
  **用 right/bottom 不用 left/top/translate**，避免和 inline 打架。
- 补了 resize 时重算位置。
