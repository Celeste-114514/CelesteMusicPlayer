## 发现的实质问题
1. **【真实隐患·内存损坏】多声道下 `_carry` 缓冲溢出**：`EchoCoreOutput.cs:42` 与 `NativeCoreOutput.cs:54` 用 `new byte[7]`，注释假设 blockAlign≤8。但 `leftover < _srcBlockAlign`，若源为多声道（如 5.1=24 字节对齐），`leftover` 可达 23 字节，写入 `_carry[7]` 会堆溢出。修复：把 `_carry` 尺寸绑定到实际 `_srcBlockAlign`（Init 时 `new byte[_srcBlockAlign]`）或加长度守卫。当前若上游恒立体声则不会触发，属潜伏炸弹。
2. **【性能 bug】`NativeWasapiExclusiveOut.ConvertToFloat` (756-771) 每次渲染回调 `new float[]` + `new byte[]`**：在音频渲染线程持续分配 → GC 压力 → 可能毛刺/欠载。应复用预分配/ArrayPool 缓冲。仅设备不支持源格式（走转换路径）时触发。
