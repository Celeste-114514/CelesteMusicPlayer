# 托盘右键崩溃、命令与尺寸修复

用户确认上一项实时 DSD 修复已经解决断音。当前优先项：托盘右键从偶发崩溃发展为每次崩溃，菜单选项曾不生效，外观瑕疵暂无法复现。

已确认的代码问题与修正：
- 从 Shell_NotifyIcon 的原生窗口回调直接进入 WebView2 异步显示流程：改为先投递 DispatcherQueue，返回原生消息循环后再运行；显示及预热显式安装 UI SynchronizationContext，防止 Task.WhenAny 后操作跑到线程池。
- WebMessageReceived 里直接执行退出/开窗命令：改为投递 UI 队列，避免在 WebView2 回调栈中销毁控制器或嵌套激活窗口。
- 快速重复右键可能重叠等待/显示：增加打开中守卫，关闭后异步续跑增加 disposed 检查；导航失败/超时不再标记菜单就绪。
- 鼠标悬停的原始条目下标包含分隔线，却当作有效按钮下标使用；去掉悬停强制 focus。DOM focusout 不能代表点击菜单外，关闭交给原生失活消息。
- 控制器 Bounds 的物理尺寸被再次除以 DPI：移除重复换算，避免高 DPI 裁切露底。勾选图标改为 SVG。

验证：WebShellTraySmoke.cjs 在 Edge headless 验证鼠标悬停不抢焦点、点击动作、上下键跳过禁用项及分隔线、Enter执行、无错误 blur 消息。崩溃事件只提供 Application.Start 栈，不能据此声称已证实唯一崩溃根因；以上为代码风险修复，实机右键/动作及多 DPI 回归仍需验证。
