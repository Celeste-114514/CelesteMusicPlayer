## 这一轮做了什么

### 控件（方案 §3、§8 第一批）

**下拉改成"原地增强原生 select"** —— 这是这一轮最关键的设计决定，和调查文档里设想的做法不同。

原设想是"藏起原生 select + 插一个自绘按钮"。实测这条路会砸布局：
标签表的排序规则是 `grid-template-columns:minmax(100px,1fr) 90px 60px 60px`，
DSP 的 `.dsp-select` 是 `grid-column:2/-1`，插一个兄弟节点就会多占一格；
设置页的 `.set-control`、网络页的 `.set-row>select` 也是各自有位置规则。

现在的做法：**原生 select 就是触发器**。它保留值、尺寸、位置、读屏语义和 Tab 顺序，
我们只接管外框、箭头、焦点圈；点开时用自绘 listbox 接管展开层。
读屏与 Tab 顺序里只有一个控件，不会出现"看不见的原生控件 + 自绘按钮"两个。

连带好处：不用再维护"select 的值镜像到按钮文字"那套 setter 包装，
原生 select 自己显示当前值，代码少了一大半。

| 文件 | 作用 |
|---|---|
| `ui-controls.js` | 下拉组件（原地增强）、共享模态、复选框/开关/滑杆/输入框的令牌层 |
| `ui-controls.css` | 控件层样式，**加载在所有页面样式之后**（index.html 最后一行） |
| `popup-manager.js` | 共用浮层：层级、贴边翻转、外部点击、Esc、焦点恢复 |
| `motion.js` / `motion.css` | 动效控制器与语义时长/位移令牌 |

其它控件侧：
- 复选框/开关/滑杆/输入框统一到 `--input-bg/--input-line/--focus/--hover/--pressed` 等令牌；
- 标签页的原生 `confirm()` 换成页面内共享模态（只有最上层响应 Esc，焦点还给触发者）；
- 标签的"显示列"选择器从左栏面板挪进共用浮层 —— 之前它被左栏自己盖住（冒烟脚本点"显示注释"时被拦截就是这个）；
- 标签表头"全选"支持**部分选中**（indeterminate）状态；
- 清掉硬编码粉色焦点框：`tags.css` / `dsp.css` / `settings.css` / `shell.css` 四处换 `--focus`；
- 字符冒充图形改 SVG：专辑/歌曲封面占位音符（`albums.js` / `shell.js` / `transport.css` / `songs.css` / `library.css`）。

### 动效（方案 §4、§7、§8 第二批前半）

- `motion.js` 是唯一的时长与幅度来源：页面转场、浮层进出、列表 FLIP、按压回弹都走它。
  同一元素上的新操作会取消旧动画并推进 generation —— 旧动画结束不会把刚打开的层关掉。
- **速度语义换了方向**：预设里存的是旧的"时长倍率"（大 = 慢），网页要的是"速度"（大 = 快）。
  宿主派生时取倒数换算，旧的个人预设也按同一规则转换，不静默颠倒用户偏好。
- 宿主新增动效偏好：`motionMode`（跟随系统/完整/轻量/关闭）、`motionSpeed`（0.6–1.6，越大越快）、
  `motionStrength`（0–1.25）、`motionBounce`（克制/柔和/灵动）。
  **单独存放，不随外观预设切换** —— 换配色不该把用户调过的动效重置。
  旧的两条覆盖项（`light:motion-speed`）从外观页数值表里移除，改由新通道接管。
- 外观页新增「动效」卡：模式四选一、速度/幅度两个滑杆、回弹风格三选一、演示按钮。
- 页面转场接进控制器：`shell.js` 的 `navigate()` 走 `CelesteMotion.page()`，
  返回键反向，`pendingDirection` 记方向。
- 顺手修了一个隐性 bug：`--motion-continuity` 和 `--motion-fast` 这两个 token **从来没定义过**，
  `library.css` 与 `transport-panels.css` 里 30 处 transition 因此整条作废 ——
  专辑卡片、音频面板的悬停/按下一直是瞬变。补上别名后这些过渡才真的在动。

## 踩到的坑（留给以后）

1. **原生控件不要藏起来再插兄弟节点** —— grid/flex 一格放不下。原地增强最省事。
2. **统一控件层要放在所有页面样式之后加载**，否则页面里 `background:` 简写会顺手清掉我们画的箭头图
   （箭头用 `background-image:...!important` 单独钉住，底色和边框仍归页面管）。
3. **同一个 select 可能被扫两次**（自动挂载先扫到、模块随后带参数调用）——
   `enhanceSelect` 要能把新参数**并进**已有实例，而不是直接返回旧的。
4. `file://` 下 `document.styleSheets` 读 `cssRules` 会抛安全错误 → 想扫 CSS 里的硬编码颜色，
   得在 Node 里直接读文件，别指望在页面里读样式表。

### DSP

| 做了什么 | 之前是什么样 |
|---|---|
| 导航共用一个指示条，换项时滑过去 | 每项自己改右边框颜色 —— 旧的瞬间消失、新的瞬间出现，没有连续感 |
| 模块内容到位后才播放入场 | 直接 `replaceChildren`，数据回来时"啪"一下出现 |
| 机架上移/下移：行从旧位置滑到新位置 | 整块重画，看不出哪一行动了 |
| 模块/方案/机架读取失败就地给「重试」 | 停在一句错误上，只能切走再切回来 |
| 参数写回被拒：值重绘回真值 + 整块闪一下 | 会重绘，但没有任何"这一下没生效"的提示 |

三个细节值得记下来：

1. **指示条必须 `z-index:1`。** 导航项自己是 `position:relative`，DOM 里排在指示条之后，
   不加这一层会被当前项那层半透明渐变盖住 —— 肉眼看到的是"一条洗淡的粉边"，
   而不是没生效（这个问题第一次截图就抓到了）。
2. **重绘分两种。** `renderModule()` 是"换模块"，放入场；`renderModule(false)` 是"参数回读后的刷新"，
   不放入场。开关类的控件写回成功后会重绘一次，如果照放动画，每拨一下整块内容都在晃。
3. **机架重排不能用通用 FLIP。** 重排会重建 `<li>`，`motion.flip(elements, mutate)` 那套
   要求前后是同一批节点，对不上。改成按模块名记下旧位置，重排后逐行算位移 ——
   只有真的移动过的行才产生动画对象。

## 第三批（续二，提交 `9285f64`）：背景交叉淡变

换背景类型（纯色 / 渐变 / 封面 / 图片）原来是"啪"一下换掉，现在旧的那层留在上面淡出。

做法：`background.js` 记住**上一帧真正画出来的**那层背景（`#bg-layer::before` 的 computed
`background-image`），变化时把它做成一张静态叠层 `.bg-ghost`，复用 `::before` 的几何与滤镜
（`inset:-6%` / `blur` / `brightness`），淡完自己移除。

两个关键决定：

- **签名只放「类型 + 图片地址」**，不比较颜色。拖外观滑杆时渐变颜色一直在变，
  那种时候跟着淡变只会把画面糊成一片 —— 而且每一帧都会插一层新叠层。
- **叠层 `pointer-events:none`**，不挡点击：外观页在预览/撤销时下面还有一堆控件要能点。

背景冒烟补了三条：换类型时有旧层在淡出、淡出的那层确实是切换前的渐变、结束后不残留。

## 第三批（续三）：加载态防闪烁 + EQ 曲线插值

提交：`5486a16` / `399c66c`（加载态与抽屉）、`ac486a8` / `aca5296`（EQ 插值）。

### 加载态防闪烁

`motion.pending(element, 180)`：先把占位藏起来，超过 180ms 还没回来才显示。
DSP 三处（模块内容、听音方案、机架编排）接上。**读失败时也要 cancel** —— 否则会留一个
转圈的架子挡住下面刚出现的重试按钮。

同一轮把两处"收尾时长写死"改成走令牌：音频链抽屉的 240ms（调慢速度后抽屉会先被藏起来、
动画还没放完）、封面交叉淡变的 450ms。抽屉还补了"退场期间又被打开"的令牌守卫。

### EQ 曲线插值

换预设 / 撤销 / 重置之后，曲线从旧增益滑到新增益（150ms），不再整条线瞬移。

三个关键决定：

1. **只画不改**：插值期间用 `drawBands` 顶替 `state.bands` 给绘图用，真实状态一直是新值。
   回读、保存、拖动拿到的永远是干净的终值，不会有人读到"半截曲线"。
2. **段数对不上就不插值**：换了段数（5 段 → 10 段）还硬插，会得到一条谁也没要求过的过渡曲线。
3. **开始前先把画面钉在旧增益上**：`tweenTo()` 里同步写一次 `drawBands`。
   否则调用方紧接着那一帧画的是终值，等于先闪一下终值再倒回来滑 —— 比不插值还难看。

手动拖动立刻接管（`changed()` 里取消插值帧）；关掉「控件」分类后不插值。

验证：新增 `tools/WebShellEqTweenSmoke.cjs`，其中最关键的一条是**"60ms 时既不是旧曲线也不是终值"**
——只断言"变了"是假的（没有插值时 60ms 也早就变完了）。
**24 个网页冒烟全过**（Browse 一次 139 段错误、AppearanceIntegration 一次超时，都是本机噪音，重跑即过）。

## 缺陷修复：DSP 页不跟随外观（提交 `1ef780c` / `3c088f4`）

用户报的现象：外壳是深色，DSP 整页还是一块白板（模块面板、导航、EQ 曲线区全白），
24 套外观预设一个都吃不到。

**根因是"三层样式各写一套死色"**：DSP 页叠了 `dsp.css`（Celeste 自己）+ `dsp-echo.css` +
`dsp-reference.css`（两层 ECHO 参考皮肤），合计约 940 个硬编码色值。
之前的外观改造用 `_theme_var_sweep.py` 逐页清理硬编码，但那个脚本**明确把 DSP 排除**了
（怕把 EQ 曲线/频谱这类功能性配色刷成强调色），所以 DSP 一直没被清理过。

修法分两段：

1. **`dsp.css` 的 66 处中性色换成语义变量**（`--panel` / `--surface` / `--line` / `--muted` /
   `--ink` / `--accent-soft`）。卡片、边框、文字、芯片一起跟着预设走 —— 浅色换强调色也生效，
   不只是深浅切换。
2. **新增 `dsp-theme.css`（最后加载）**，补 ECHO 两层里写死的浅色：面板/压缩器卡片、
   原生 `input`、琥珀色小按钮、靛蓝色"已选中"芯片。

两个关键判断：

- **EQ 曲线区**：深色调色板其实早就写在 `dsp.css` 里（`--eq-grid` / `--eq-stop-*` / `--eq-node`
  两套值都有），但只认 `.eq-curve-wrap[data-dark=true]`，而**没有任何代码去设这个属性**。
  现在把 `html[data-theme="dark"] .eq-curve-wrap` 加进同一个选择器即可，JS 不用改。
- **功能性配色一律不动**：EQ 三段渐变、电平表的绿、声道偏差表上那根白色指针，都是"读数"，
  不跟外观漂。冒烟里把白色指针列成唯一允许的例外。

验证：新增 `tools/WebShellDspThemeSmoke.cjs` —— 深色下扫遍 11 个 DSP 模块，
"不透明且亮度 > 0.6"的元素必须为空；EQ 曲线区随主题换色；切回浅色面板恢复浅色。
