# W11 首版：任务栏内部播放条

用户已确认 inside.png 并授权实现。实现落点为独立 Win32 NOACTIVATE/TOOLWINDOW/TOPMOST HWND + 共用环境的 WebView2，位于主屏任务栏矩形内部，不占工作区。参考 ECHO 定位与状态/命令分离的思路，未复制 ECHO 源码或资产，也未引入 Electron。未更改 WorkBuddy 的托盘修复。

## 已实现

- 设置 → 常规与启动 → 任务栏内播放条，默认关闭；AppSettingsStore.Clone、设置读写白名单和即时应用均接入。重启按设置恢复。
- 复用 WebPlaybackState、现有封面资源处理和播放命令；无独立引擎。显示封面/标题/艺术家、上一首/播放暂停/下一首及只读进度；双击信息区域恢复主网页。右键隐藏或打开设置；隐藏持久化关闭开关。
- 按任务栏 DPI 换算尺寸，图标居中时放左侧、左对齐时放通知区前；已有 Widgets HWND 的占位会避开。底色从任务栏边缘取样，文字按亮度适配。
- 任务栏自动隐藏、非底部任务栏、全屏窗口、空间不足时隐藏并记日志；Explorer HWND 重建时重新定位/登记 AppBar。与同位置可见 ECHO 播放条重叠时隐藏，避免相互遮挡。
- 关闭功能/退出程序停止计时器、关闭 WebView、注销 AppBar/窗口类、销毁 HWND。初始化最多失败三次，不无限重试。

## 验证与实际限制

- Release build 与自包含 publish 成功。第一次构建遭 CLR/MSBuild 日志线程异常，关闭构建服务后重试成功。
- TaskbarPlayerRegression：正负屏幕坐标、两种对齐、100/125/150/200% DPI、Widgets 占位和空间不足通过。
- WebShellTaskbarPlayerSmoke：100–200% DPI 下按钮动作、双击恢复、右键菜单消息、忙碌禁用、进度边界、标题按文本显示及无溢出通过。
- 未调用 computer-use，未开启用户设置、启动播放器或操作其窗口；以上不等于 Windows 任务栏完整实机验收。默认开关仍关闭。
- 第一版仅支持主屏底部任务栏；自动隐藏任务栏暂不显示，多屏选择、侧边布局未实现。普通 HWND 的系统层级兼容性仍需实测；未启用 undocumented window band。
- 位置计算会避开已识别的 Widgets/通知区和窄屏中心区域，但尚未逐个枚举全部第三方任务栏扩展或大量应用按钮的实际占位。需人工确认不遮挡；不满足时可立即关闭功能。不将此项写为 W11 完整验收通过。
