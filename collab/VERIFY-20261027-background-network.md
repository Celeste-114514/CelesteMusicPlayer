# 背景、外观撤销与网络来源：实现与验证记录

日期：2026-10-27。此记录区分源码/模拟验证与真实账号验收。

## 已实现

- 外观：不可变图片/视频资源、静音循环视频、隐藏/最小化暂停与恢复、退出视频模式释放媒体源、读取/解码错误提示。
- 外观操作统一草稿：参数、背景、字体、导航、底栏、明暗、强调色和预设可撤销；保存才持久化，取消恢复已保存外观。历史保存原始覆盖表，撤销到基线后覆盖数归零。请求串行，失败不移栈，不同拖动手势分开。
- 两套系统风格：Windows · Fluent、Apple · 银白，均有浅/深色和各自几何、排版、透明度。
- 网络：WebDAV、百度网盘、Jellyfin、Emby、Subsonic/Navidrome、SMB、SSHFS 的来源管理、测试、浏览、索引同步、取消同步、按需下载原文件；现有 WebDAV 自动迁入来源列表。SMB/SSHFS 使用系统已有挂载，不内置 SSH 客户端/驱动。
- 网络曲目稳定编号；临时链接/缓存版本不作编号；本地普通歌曲继续兼容原路径，CUE 与网络引用采用 track-refs 映射。网页统一歌曲/专辑/收藏/歌单/历史，增加来源筛选；专辑按来源隔离。
- 支持文件型网络来源的配套 CUE（需开启 AutoApplyCueOnScan）、多 FILE 与首轨零起点；分轨共用音频缓存。服务器来源使用其已暴露的歌曲，不假定能读取隐藏 CUE。
- 混合歌单持久引用与版本化 JSON 导入导出；普通路径列表保持 M3U8。导出不含凭据，导入的新网络来源默认禁用，需要重新配置账号。
- 新增独立 network-library.db，不替换旧本地 tracks 表。DPAPI 加密凭据，快照不回传原文；同步取消/失败不标记整库缺失；播放/预载缓存租约与缓存清理、上限控制。

## 实际限制与后续验证

- 未完成真实用户服务器/百度账号授权验收；模拟协议验证不代表所有服务端版本均认证兼容。百度需要自己配置的应用身份或已有 Token，未复制 ECHO 的 AppKey/Secret。参考协议：Subsonic 官方 API、Jellyfin 官方 SDK、Emby 官方认证与静态音频文档；本机 ECHO 仅用于结构和能力参考。
- 此轮没有彻底替换本地库全部路径模型；普通本地移动/重命名仍沿用旧机制。旧整轨播放统计不会被复制为多份分轨播放次数。
- 协议中请求原始文件，不能仅凭请求参数宣称端到端 bit-perfect；继续以现有解码/DSP/输出判据为准。
- 此记录时尚未运行更新产物的原生启动冒烟；后续标签修复阶段会继续验证。用户已将当前工作转向标签表格及动画调研。
