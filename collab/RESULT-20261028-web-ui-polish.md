# 网页 UI 正式入口、窗口/波形修复与两份设计方案

日期：2026-10-28。承接上一轮尚在收尾的材质与音频仪表改造，以及本轮新增的双层窗口、波形线条与方案要求。

## 已修复/实现

- **单一窗口外观**：WebShellWindow 使用 `SetBorderAndTitleBar(true, false)` 保留原生缩放边框，移除系统标题栏；只保留网页的一套窗口按钮。启用 WebView2 非客户区域支持，标题空白处可拖动、双击最大化；按钮/输入/选择区不参与拖动。网页外壳去掉整圈 padding、描边与圆角，内容贴满窗口。
- **底栏波形**：固定 480×34px，96 根柱，每根 3px、柱间 2px。窗口宽度变化不重新分组采样、不拉伸柱形；周围布局适配窗口。整体字号和其它底栏偏好仍有效。
- **详情页左栏**：移除独立滚动容器，播放键悬停缩放不再触发滚动条；矮窗口缩小封面，窄窗口采用紧凑封面/信息布局，歌词保留独立滚动。
- **音频仪表**：界面名称改为“音频仪表”，旧 `twilight` 保存值自动迁移。按用户视频改为细密黑色竖条、移动圆环标记、整曲波形与时间轴、音频参数。后端新增 140 个对数频带的无高频补偿 FFT 输出，保留原 40 频带消费者；前端取样约 20Hz，与 requestAnimationFrame 插值绘制分离，绘制限约 60fps。暂停保留频谱画面并停止采样，隐藏/退出也停止。没有采样时明确说明，不伪造数据。
- **Windows/Apple**：落实亚克力宿主背板、网页透明链、浮层磨砂、高光/阴影、控件几何、Apple 悬浮底栏与播放控件组，支持浅深色及减少透明度。材质参数进入现有草稿、保存、取消流程；个人预设保存材质类型。
- **正式网页入口**：无启动参数即进入网页主窗口；原 MainWindow 作为隐藏的既有播放/控件后端保留。移除返回原 UI 的产品入口；托盘恢复和文件激活进入网页会话，关闭网页不再唤回旧主界面。原源码和零散窗口实现保留供未来维护。
